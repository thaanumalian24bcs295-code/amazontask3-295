# Amazon Product Cart

A React application demonstrating Components, JSX, Props, State, and Hooks.

## Features
- Wireless Mouse priced at ₹499
- Black, Blue, and White colour selection
- Editable delivery city
- Add to Cart, Remove One, and Reset Cart
- Dynamic total calculation
- Show/Hide Product with state preservation
- React useState and useEffect

## Technologies
- React
- JavaScript
- JSX
- CSS
- Vite

## Run the Project

Install dependencies from the root folder:

npm run setup

Start the React frontend:

npm run client

## Expected Result

Adding two products displays a total of ₹998.
